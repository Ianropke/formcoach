# FormCoach Web PWA

This directory contains the canonical FormCoach application.

## Stack

- React + TypeScript + Vite
- MediaPipe Tasks Vision running locally in the browser
- deterministic movement analysis under `src/core/`
- local structured history in IndexedDB

## Commands

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

See the repository root documentation for product behavior, architecture, evidence semantics, privacy, and current project state.
